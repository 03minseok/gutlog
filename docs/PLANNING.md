# 것로그(gutlog) 기획 문서

## 0. 프로젝트 목표
- **서비스**: gutlog — UC(궤양성대장염) 환자를 위한 증상 기록·분석 앱
- **개인**: 개발자 본인이 UC 환자이기 때문에, 본 서비스 개발을 통해 다른 환우분들뿐 아니라 저도 유용하게 이용하고 싶습니다. 개발 과정에서 최대한 직접 코드를 작성하려고 하며, AI 시대 전 마지막으로 직접 구현해보는 프로젝트로 남기고 싶습니다.
- **v1 목표 시점**: 2026년 10월

## 1. 문제 정의
- **대상 사용자**: UC 환자 및 보호자 (특히 자신의 트리거 음식을 아직 파악하지 못한 환자)
- **겪는 문제**: 정보 수집의 어려움, 그리고 행동(복용·식사 등)과 증상 사이의 상관관계를 추적하기 어려움
- **기존 방법(수첩·메모앱)으로 부족한 이유**: 기록은 되지만 행동과 증상을 이어 패턴을 찾아주지는 못한다. "그저께 뭘 먹었더라"를 사용자가 직접 뒤져야 한다.

## 2. 해결 방식
매일 식사·복용·배변을 기록해 행동과 증상 사이의 상관관계를 추적한다. 사용자는 흩어진 기록을 직접 뒤질 필요 없이, 앱이 "무엇을 먹은 다음 어떤 증상이 나타났는지"를 대신 집계해 보여준다.

## 3. 핵심 기능 (v1 범위)
- **기록**
  - 식사: 시간, 먹은 음식
  - 복용: 먹은 약, 먹은 양
  - 배변: 혈변·통증 등 배변 양상
- **분석**: 특정 음식을 먹은 다음날 혈변·복통이 나타난 빈도를 집계한다. (예: "매운 음식을 먹은 12번 중 8번 다음날 혈변") 데이터가 적을 때는 분석 대신 "기록이 더 필요해요"로 안내한다.

## 4. 향후 로드맵 (v2 이후)
- **v2**: 정보 제공 (논문·신약 등 UC 관련 정보 업데이트) + 보호자-환자 연결
- **v3**: 커뮤니티 (환우 간 증상·정보 공유의 장)

## 5. 사용자 흐름
가입 → (매일) 식사·복용·배변 기록 → 기록이 쌓이면 분석 화면에서 내 패턴 확인 → 트리거를 파악해 관리에 활용

## 6. 이 프로젝트에서 배우고 싶은 것
새 기술을 미리 정해두기보다, 구현하다 막히는 지점에서 필요한 것을 배운다. 기능마다 "왜 이렇게 했는지"를 기록으로 남긴다.
