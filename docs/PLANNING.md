# 것로그(gutlog) 기획 문서

## 0. 프로젝트 목표
- **서비스**: gutlog — UC(궤양성대장염) 환자를 위한 증상 기록·분석 앱
- **개인**: 개발자 본인이 UC 환자이기 때문에, 본 서비스 개발을 통해 다른 환우분들뿐 아니라 저도 유용하게 이용하고 싶습니다. v1까지는 개발 과정에서 최대한 직접 코드를 작성하려고 하며, 이후 v2 부터는 AI툴을 적극 활용하여 프로젝트를 완성시킬 계획입니다.
- AI툴로 구현 이후 핵심 기능은 개발자 본인이 직접 구현해서 복기합니다.

## 1. 문제 정의
- **대상 사용자**: UC 환자 및 보호자 (특히 자신의 트리거 음식을 아직 파악하지 못한 환자)
- **겪는 문제**: 정보 수집의 어려움, 그리고 행동(복용·식사 등)과 증상 사이의 상관관계를 추적하기 어려움
- **기존 방법(수첩·메모앱)으로 부족한 이유**: 기록은 되지만 행동과 증상을 이어 패턴을 찾아주지는 못한다. "그저께 뭘 먹었더라"를 사용자가 직접 뒤져야 한다.

## 2. 해결 방식
매일 식사·복용·배변을 기록해 행동과 증상 사이의 상관관계를 추적한다. 사용자는 흩어진 기록을 직접 뒤질 필요 없이, 앱이 "무엇을 먹은 다음 어떤 증상이 나타났는지"를 대신 집계해 보여준다.

## 3. 버전별 기능
- **v1(구현완료)**
  - 식사 기록: 시간, 먹은 음식
  - 복용 기록: 복용 약 관리 및 날짜별 복용 체크
  - 배변 기록: 혈변·통증 등 배변 양상
  
- **v2**
  - 기록: 체중, 수면 기록
  - 정보 제공: 논문·신약 등 UC 관련 정보 업데이트
  - 보호자-환자 연결
  - 분석: 특정 음식을 먹은 다음날 혈변·복통 빈도를 집계 (예: "매운 음식 12번 중 8번"), 데이터가 적으면 분석 대신 데이터가 더 필요하다는 문구 송출.
- **v3**
  - 커뮤니티 (환우 간 증상·정보 공유의 장)
  - 기타 추가 기능

## 4. 기본 사용자 흐름
가입 → (매일) 식사·복용·배변 기록 → 기록이 쌓이면 분석 화면에서 내 패턴 확인 → 트리거를 파악해 관리에 활용

## 5. 이 프로젝트에서 배우고 싶은 것
새 기술을 미리 정해두기보다, 구현하다 막히는 지점에서 필요한 것을 배운다. 기능마다 "왜 이렇게 했는지"를 기록으로 남긴다.
